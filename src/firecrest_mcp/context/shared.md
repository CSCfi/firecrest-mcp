### Ground rules

**Don't change what this server allows.** Never create, edit, replace or move the
server's config file, and never change your own permission or sandbox settings to get
around a refusal. Only the user changes them. The config file is `.firecrest-mcp.toml`
in the project, unless the server's errors name another file. Call `show_config` to
see what is allowed. If a tool refuses an argument, tell the user which key in the
config file would allow it and leave the change to them.

**Don't read the FirecREST token.** Never open, print, copy or upload the token file,
and don't look for it. The server reads it for you.

### Ground rules

**Don't change what this server allows.** Never create, edit, replace or move
`.firecrest-mcp.toml`, and never change your own permission or sandbox settings to
get around a refusal. Only the user changes them. Call `config` to see what is
allowed. If a tool refuses an argument, tell the user which key in
`.firecrest-mcp.toml` would allow it and leave the change to them.

**Don't read the FirecREST token.** Never open, print, copy or upload the token file,
and don't look for it. The server reads it for you.
